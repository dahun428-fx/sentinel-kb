## 백로그 추가 이력

- **T-036 (T-007 R-7 / T-012에서 확정)** — `specs/04:29`가 "`packages/contracts`에서 zod-to-openapi로
  생성, **`/v1/openapi.json` 서빙**. 수기 작성 금지"를 요구하는데 **어느 태스크에도 배정돼 있지 않았다.**
  `openapi.ts`에는 오퍼레이션이 이미 등록돼 있으나 라우트가 없어 **문서와 구현이 어긋난 창이 열려 있다.**
  스펙이 있는데 구현이 없는 경우라 "스펙 없는 신규 API 추가 금지"의 반대 사례다 — 방치하면 드리프트가 는다.
  T-012에 끼워 넣지 않은 이유: 그쪽 Scope가 검색 라우트로 한정돼 있고, T-010·T-011에서 스코프 초과가
  연속으로 G5에 걸렸다. 별도 태스크가 규약에 맞다.
